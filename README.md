# calculator-app

a simple calculator app built with the programming languages: kotlin and java, alongside gradle open-source automation tool
more stuff will be added, changed, implemented, or integrated later on.

this is only a 4-function calculator. will eventually get to scientific, then graphing (TI-84 Plus CE or the EVO.)

## features:
addition, subtraction, multiplication, and division
decimal number support
division-by-zero error handling
clear and backspace buttons (dont believe that computer keyboards wont work for this, so you gotta use the touchpad or mouse to press the buttons)
calc keyboard input (not talking about the computer/laptop keyboard functioning for the buttons)
dark-themed UI
calculation history

## tech used
Java - calculation engine
Kotlin - desktop graphic interface
Gradle - build automation and dependency management
JUnit 5 - automated unit testing
Java Swing - graphical UI

## project structure
CalculatorEngine.java - mathematical operations
CalculatorEngineTest.java - automated tests
Main.kt - application entry point
CalculatorWindow.kt - calculator interface and interaction logic

## project run
1. open the project in IntelliJ IDEA
2. allow Gradle to synchronize
3. open Main.kt
4. Run the main() function.
